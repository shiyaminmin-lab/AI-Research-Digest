# AI Research Digest Skill

一份可按读者专业背景调整的中文 AI 前沿研究型日报 Skill。它不是新闻爬虫：生成时会重新检索来源，区分已确认事实、外部观点与自己的分析，重点解释 2–3 件事件，并保留原始链接与仍待验证的问题。

**心理学只是一个使用示例，不是默认立场。** 读者也可以从教育、产品设计、运营、法律、医疗、研究或其他专业出发；重大 AI 新闻不会因为和专业无关而被删掉。

## 安装

在 Codex 中请 `skill-installer` 安装本仓库，或将包含 `SKILL.md` 的 `ai-research-digest` 文件夹放到你的个人 Skills 目录。具体目录和发现方式请以 [OpenAI 官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills) 为准。安装后可以说：“使用 `$ai-research-digest`，生成今天的 AI 研究型日报。”

本仓库只有提示词、说明与示例，没有抓取脚本，不需要 API 密钥。使用时的联网与消息权限取决于你的 Codex 环境；安装本 Skill **不会**自动创建定时任务、发送消息或运行第三方 `follow-builders` 脚本。

## 先告诉 Skill 你是谁

不提供画像也能使用。若希望它贴近你的专业，第一次可附上一段简短说明：

> 我是【专业／岗位】，做过【已确认的经验】，熟悉【已知内容】，想补足【知识缺口】，主要关注【地区／议题】。请用【期望篇幅】整理全球 AI 进展。只有确实相关时，才从我的专业提出可验证的问题；不要把我没做过的事写成经历，也不要把所有新闻都强行套进我的专业。

例如：

- **心理学／咨询**：关注人机信任、依赖、自主性及风险识别。请区分来源支持的结果与我可以继续研究的问题；不把新闻直接当临床证据。
- **教育**：关注学生学习成效、教师工作分工和评估方式。若新闻只报告产品上线，不要推断学习效果已改善。
- **产品／UX**：关注真实用户任务、采用障碍、监督与接管、成功指标。请给出可执行的用户访谈或验证问题。
- **运营／组织**：关注流程改造、培训、责任分配和实际成本。不要仅凭公司演示推断已节省人力。

以上是**提问视角**，不是先验结论。医疗、法律、金融等领域还需相应的专业核查，日报不能替代个案建议。

你也可以复制 [`examples/reader-profile.example.md`](examples/reader-profile.example.md) 为本机 `references/reader-profile.md`，填写自己的偏好。这个私有文件已被 `.gitignore` 排除；请仍在上传前检查仓库内容，不要公开个人资料、案例、凭证或未授权材料。每次请求中的新说明优先于本地画像。

## 它如何组织一份日报

1. 今日全景：只做导航，不与正文重复。
2. 重点事件：2–3 件完整解读，分开【来源事实】【作者观点／外部反响】【我的分析】，专业关联只在确有价值时出现。
3. 其他值得知道的进展：补足全球行业覆盖。
4. 专业视角／Human-AI 启发：提出有来源基础、可验证的问题；没有合适材料就省略。
5. 术语、持续追踪和编辑复盘：帮助积累概念与校准阅读难点。

需要修改写法时，直接编辑 `SKILL.md`；个人偏好放在本机画像或每次请求里。**本地修改不会自动同步到 GitHub**：发布更新需要提交并推送，其他人安装的副本也不会因此自动更新。
